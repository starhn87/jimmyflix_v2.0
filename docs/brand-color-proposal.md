# Jimmyflix 브랜드 컬러 제안

## 판단 기준

브랜드 컬러는 콘텐츠 포스터보다 먼저 보이기보다 탐색을 돕는 역할이 중요하다. 다음 기준으로 세 가지 방향을 비교했다.

- 다크·라이트 테마 모두에서 본문, 링크, 포커스 링, 주요 버튼의 대비가 WCAG AA를 만족할 것
- 영화·TV 포스터의 색을 방해하지 않고 검은 화면에서도 브랜드를 식별할 수 있을 것
- J 티켓 아이콘과 작은 favicon에서도 한눈에 구분될 것
- IMDb 노랑, 별점 노랑, 오류 빨강처럼 이미 의미가 정해진 색과 충돌하지 않을 것

## A. Ticket Cyan

기존 J 티켓의 청록→파랑을 브랜드의 출발점으로 삼고, 화면 바탕을 잉크빛 네이비로 정리하는 방향이다. 기존 사용자에게 낯설지 않으면서 아이콘과 UI의 연결이 가장 선명하다.

| 역할 | 다크 테마 | 라이트 테마 |
| --- | --- | --- |
| Canvas | `#070B14` | `#F5F8FC` |
| Surface | `#111827` | `#E8EEF6` |
| Primary | `#22D3EE` | `#0369A1` |
| Primary hover | `#67E8F9` | `#075985` |
| Secondary / gradient end | `#2563EB` | `#1D4ED8` |
| Text on primary | `#041014` | `#FFFFFF` |
| Highlight | `#FBBF24` | `#92400E` |

- Primary와 Canvas 대비: 다크 10.89:1, 라이트 5.57:1
- 주요 버튼의 글자 대비: 다크 10.67:1, 라이트 5.93:1
- 장점: 기존 아이콘을 유지할 수 있고, 포스터 위 포커스·선택 상태가 또렷하다.
- 주의점: 청록을 넓은 배경에 많이 쓰면 기술 서비스처럼 보일 수 있으므로 버튼, 활성 탭, 포커스, 짧은 강조에만 사용한다.

## B. Marquee Amber

극장 간판과 티켓 조명을 떠올리는 앰버 계열이다. 따뜻하고 영화다운 인상은 강하지만, IMDb와 별점에 이미 노랑이 사용되어 의미 구분이 약해질 수 있다.

| 역할 | 다크 테마 | 라이트 테마 |
| --- | --- | --- |
| Canvas | `#0D0B09` | `#FFF9F0` |
| Surface | `#1C1712` | `#F4E8D7` |
| Primary | `#F59E0B` | `#B45309` |
| Primary hover | `#FBBF24` | `#92400E` |
| Secondary / gradient end | `#EF4444` | `#B91C1C` |
| Text on primary | `#1C0F02` | `#FFFFFF` |

- Primary와 Canvas 대비: 다크 9.15:1, 라이트 4.80:1
- 주요 버튼의 글자 대비: 다크 8.74:1, 라이트 5.02:1
- 장점: 영화관과 시사회 분위기가 직접적이고 따뜻하다.
- 주의점: 평점·IMDb 노랑과 겹치고, 빨강을 함께 쓰면 다른 스트리밍 브랜드와 인상이 가까워진다.

## C. Velvet Violet — 선택

어두운 상영관과 프리미어 조명을 연상시키는 보라 계열이다. 엔터테인먼트 분위기와 양 테마의 대비가 좋지만, 현재 J 티켓을 다시 디자인해야 일관성이 생긴다.

| 역할 | 다크 테마 | 라이트 테마 |
| --- | --- | --- |
| Canvas | `#0B0912` | `#FAF8FF` |
| Surface | `#181326` | `#EEE9F8` |
| Primary | `#A78BFA` | `#6D28D9` |
| Primary hover | `#C4B5FD` | `#5B21B6` |
| Secondary / gradient end | `#EC4899` | `#BE185D` |
| Text on primary | `#100A20` | `#FFFFFF` |

- Primary와 Canvas 대비: 다크 7.27:1, 라이트 6.74:1
- 주요 버튼의 글자 대비: 다크 7.10:1, 라이트 7.10:1
- 장점: 프리미엄·엔터테인먼트 인상이 강하고 접근성 대비가 안정적이다.
- 주의점: 보라→분홍 그라데이션만으로는 여러 엔터테인먼트 서비스와 비슷해질 수 있어, 배경 없는 J 티켓 실루엣을 일관되게 함께 사용해야 한다.

## 선택 결과

최종 방향은 **Velvet Violet**으로 결정했다. J 티켓은 `#A78BFA → #EC4899` 그라데이션을 사용하고, 다크 테마는 `#0B0912`, 라이트 테마는 `#FAF8FF`를 Canvas로 사용한다. 보라색은 주요 행동·현재 메뉴·활성 탭·포커스에 사용하며, 핑크는 티켓 그라데이션 안에서 브랜드 인상을 만드는 역할로 제한한다.

적용 원칙은 다음과 같다.

1. `canvas`, `surface`, `primary`, `action`, `focus`, `on-action` 토큰을 다크·라이트 테마에 맞춰 관리한다.
2. J 티켓 SVG, favicon, 헤더 활성선, 버튼, 탭, 포커스 링을 같은 보라 계열로 맞춘다.
3. 별점·IMDb·오류처럼 의미가 있는 상태색은 브랜드색과 분리한다.
4. 다크·라이트 화면을 320px와 1440px에서 확인하고 텍스트·버튼 대비를 다시 측정한다.

2026-09-10에 Velvet Violet을 앱 테마 토큰, 배경 광원, J 티켓 SVG와 favicon에 적용했다.
