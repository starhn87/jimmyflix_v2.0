# 브랜드 아이콘과 테마

## J Ticket

선택한 2번 시안을 앱용 SVG로 정리했다. 티켓 실루엣과 가운데 투명하게 뚫린 J만 사용하며, 둥근 사각형 배경·그림자·워드마크를 favicon에 포함하지 않는다.

- 원본: `app/icon.svg`, 64×64 viewBox, 청록→파랑 그라데이션.
- 호환 아이콘: `app/favicon.ico`, 16·24·32·48·64px 투명 이미지.
- 헤더는 동일한 SVG를 40×40px로 표시한다.
- App Router의 파일 기반 메타데이터가 SVG·ICO 링크와 캐시 갱신용 URL을 생성한다.
- 티켓의 가로 실루엣은 256px 렌더 기준 x=1…254px를 사용한다. 높이는 티켓의 원래 비율을 유지하고, J 내부와 바깥 여백은 투명하다.

## 테마 동작

- 헤더 오른쪽의 44×44px 토글 버튼으로 다크·라이트 모드를 전환한다. 다크 모드에는 해, 라이트 모드에는 달 아이콘을 표시한다.
- 접근성 이름은 `Dark mode`, 현재 상태는 `aria-pressed`로 전달한다. Enter·Space와 포인터로 조작할 수 있다.
- 선택은 `localStorage`의 `jimmyflix-theme-v1`에 저장한다. 선택이 없거나 유효하지 않으면 기기의 `prefers-color-scheme` 설정을 따른다.
- 저장된 선택이 없을 때 기기 설정 변경을 반영한다. 명시적으로 선택한 테마가 있으면 그 선택을 우선한다.
- 같은 사이트의 다른 탭에서도 storage 이벤트로 테마를 동기화한다.
- 저장 기능이 차단되거나 쓰기에 실패해도 현재 페이지의 메모리에 선택을 유지해 토글이 동작한다. 이 경우 새로고침 후 영구 저장은 보장하지 않는다.

## 렌더링과 스타일

`lib/theme.ts`의 짧은 고정 스크립트가 head에서 첫 화면을 그리기 전에 `html[data-theme]`을 설정한다. 브라우저 전용 설정으로 인한 HTML 속성 차이는 루트 html에서만 허용한다. 토글은 `useSyncExternalStore`로 실제 DOM 테마를 읽어 hydration 이후 접근성 상태를 동기화한다.

색상·그림자는 `app/globals.css`의 의미별 변수와 Tailwind 토큰을 사용한다. 헤더·홈/TV 목록·검색·트렌드·상세·스켈레톤·빈 화면·오류 화면을 같은 기준으로 전환한다. 사진 위 평점 배지와 영상 자막은 고정된 어두운 배경과 흰 글씨를 유지해 대비를 확보한다.

테마 때문에 쿠키를 읽거나 최상위 페이지를 Client Component로 바꾸지 않는다. 기존 정적 페이지·서버 데이터 로딩·스트리밍을 유지하고 새 패키지는 추가하지 않았다.

## 검증 기록

- Node.js 24에서 lint·TypeScript·프로덕션 빌드 검증.
- 로컬 프로덕션 서버의 고정 데이터 화면으로 1440px 카탈로그·상세·Credits·Production·로딩, 검색 화면을 시각 검증.
- 320px 상세 화면에서 헤더·메뉴·44px 토글이 겹치지 않고 가로 넘침이 0px임을 확인.
- 버튼 클릭, Enter·Space, 새로고침, 페이지 이동, 기기 테마 변경, 수동 선택 우선순위, 실제 두 탭 사이 동기화 확인.
- 테마 초기화 스크립트의 저장된 light/dark, 기본 기기 light/dark, 잘못된 저장값, 저장 접근 차단 등 7개 조건 검증.
- 저장 쓰기 실패 시에도 수동 선택이 적용되고 기기 설정 변경에 덮어써지지 않음을 확인.
- 외부 React 스크립트를 차단해도 저장된 라이트 테마와 달 아이콘이 먼저 표시됨을 확인.
- favicon의 모든 ICO 크기에서 투명 모서리와 이미지 범위를 확인. 검증용 임시 경로는 최종 소스에서 제거한다.

로컬에는 TMDB API 키가 없으므로 정상 데이터의 시각 검증은 임시 고정 데이터를 사용했다. 원격 프리뷰·운영 배포 검증은 푸시 승인 후 진행한다.
