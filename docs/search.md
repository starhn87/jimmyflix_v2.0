# 통합 검색

작성일: 2026-09-10

## 사용자 동작

- Search 내비게이션 메뉴와 검색 페이지 본문의 중복 입력창을 제거하고 헤더의 검색창 하나로 통합한다.
- 데스크톱 검색창은 최대 320px 너비로 항상 표시한다. 1024px 미만에서는 44px 돋보기 버튼으로 헤더 아래 검색창을 펼친다. 검색 페이지에 직접 접근하면 모바일 검색창이 열린 상태로 시작한다.
- 펼칠 때 입력창에 포커스를 주고, Escape로 닫으면 돋보기 버튼으로 포커스를 돌려준다.
- 플레이스홀더는 `Titles, actors, keywords`다. 제목, 배우 등 인물 이름, TMDB 주제 키워드를 같은 입력창에서 검색한다.
- 입력 앞뒤 공백을 제거하고 빈 입력은 오류 안내와 포커스로 처리한다. 입력창과 서버 모두 200자 제한을 적용한다.
- `next/form`의 GET 제출로 `/search?q=...`에 이동한다. React가 준비된 뒤에는 전체 문서를 다시 받지 않고 이동하며, 직접 접근·새로고침·뒤로가기에서도 URL의 검색어를 복원한다.
- 결과는 Movies·TV shows로 나누고 같은 유형의 같은 작품 ID를 한 번만 표시한다. 실제 반환한 결과 수는 `Showing … titles`로 표시한다.

## 검색 범위

제목은 원제·번역 제목·대체 제목을 지원하는 TMDB 영화·TV 검색을 사용한다. 인물 이름은 TMDB 인물 검색 후 해당 인물의 영화·TV 출연 및 제작 참여 크레딧으로 확장한다. `Tom Hanks`를 입력하면 제목에 그 이름이 없는 참여 작품도 결과에 포함할 수 있다.

주제는 키워드 이름 검색 후 영화·TV discover의 `with_keywords` 필터로 확장한다. 예를 들어 `time travel`은 제목에 이 문구가 없는 관련 작품도 찾을 수 있다. 키워드는 TMDB에 등록된 이름을 기준으로 하며, 임의의 문장을 줄거리 전체와 비교하거나 한국어 문장을 의미 번역하는 검색은 제공하지 않는다. 이번 범위는 사용자가 선택한 제목·배우·주제 키워드 검색이다.

## 요청과 결과 처리

`lib/tmdb.ts`가 서버에서만 API 키와 HTTP 요청을 다룬다. `lib/search.ts`는 검색 소스를 주입받아 요청 병렬화, 후보 선택, 정렬, 중복 제거, 실패 처리를 수행한다.

1. 영화 제목·TV 제목·인물·키워드 검색을 동시에 시작한다. 인물·키워드 응답이 오면 제목 응답을 기다리지 않고 해당 확장 요청을 시작한다.
2. 정확히 일치하는 인물·키워드 이름을 우선하고, 없으면 TMDB 검색 순서의 상위 후보를 사용한다. 인물과 키워드는 각각 최대 3개로 제한한다.
3. 인물 크레딧 요청은 최대 3개, 키워드 discover는 영화·TV 각 1개다. 키워드 ID는 OR 조건으로 묶는다. 전체 요청은 검색 1회당 최대 9개이며 페이지를 연쇄 수집하지 않는다.
4. 직접 제목 검색 결과를 우선하고 관련 작품은 인기도 순으로 합친다. 영화·TV 각각 최대 60개를 표시한다. 동일한 숫자 ID의 영화와 TV는 서로 다른 작품으로 유지한다.
5. 성인 제외 설정을 유지하며, 인물 크레딧에서 추가되는 작품도 같은 필터를 적용한다.
6. 검색 요청은 각각 5초 후 중단한다. 검색·주제별 목록은 5분, 인물 크레딧은 30분 캐시를 사용한다. 타이핑 중에는 요청하지 않는다.
7. 한 소스가 실패해도 나머지 결과를 유지한다. 크레딧 실패 시에는 인물 검색의 대표작을 대체 결과로 사용한다. 불완전한 결과에는 재시도를 제공하며, 모든 검색이 정상 완료된 0건만 `No matches`로 표시한다.

헤더·검색어 제목은 결과 대기 중에도 유지한다. 결과는 기존 `Suspense` 스켈레톤으로 스트리밍하며, 검색 파라미터를 읽는 헤더 부분만 별도 경계로 분리해 영화 홈·TV 페이지의 정적 생성을 유지한다. 패키지·DB·검색 서비스는 추가하지 않았다.

## 검증

- `node --test tests/search.test.mjs`: 인물 크레딧·주제 합치기, 중복 ID와 반복 출연 제거, 정확한 이름 우선, 성인 제외, 실패 시 대체 결과, 요청 및 결과 수 제한, 병렬 실행, 빈 입력·길이 제한 등 6개 테스트 통과.
- `corepack yarn lint`, `corepack yarn typecheck`, `corepack yarn build` 통과. `/`와 `/tvs`의 정적 생성 유지.
- 고정 TMDB 응답으로 실제 로컬 검색 경로를 검증했다. 검증 전용 응답은 저장소 밖의 프로세스에만 주입했으며 앱 코드와 최종 빌드에 포함하지 않는다.
- 제목 검색, 인물 이름으로 영화·TV 찾기, 주제 검색, 재검색, 뒤로가기·새로고침 시 입력 복원, 전체 문서 재로드 없는 이동을 확인했다.
- 320px에서 가로 넘침 0px, 검색 입력 너비 304px, 44px 돋보기·테마 토글, 펼침 시 입력 포커스, Escape 복귀, 공백 제출 오류를 확인했다.
- API 일부 실패 시 성공 카드 유지, 전체 실패와 정상 0건의 서로 다른 안내, 검색 페이지의 입력창 1개를 확인했다.
- 프로덕션 빌드의 로컬 서버에서도 검색·헤더·테마 렌더링과 브라우저 런타임 오류가 없는지 확인했다.

원격 TMDB 실데이터와 Vercel 프리뷰 검증은 푸시 승인 후 진행한다.
